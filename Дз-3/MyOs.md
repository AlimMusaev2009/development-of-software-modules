# Операционные системы и среды.

## Лабораторная работа — Диагностика системы

Я бы создал собственную операционную систему на базе ядра **Linux**, ориентированную в первую очередь на программистов, разработчиков и людей, которым нужны специализированные инструменты для работы.

Опишите вымышленную или настоящую ОС.
--
  - Моя операционная система была бы создана на базе ядра Linux.
  - Интерфейс системы был бы похож на Windows, чтобы им было удобно пользоваться людям, привыкшим к этой ОС.
  - При этом сама система была бы ориентирована преимущественно на программистов и разработчиков.
  - В ней было бы большое количество встроенных инструментов, которые обычно приходится устанавливать отдельно.

Расскажите о том, с чего бы вы начали.
--
  - Сначала я бы создал базовую систему на основе Linux и настроил необходимые системные компоненты.
  - Затем разработал бы собственный графический интерфейс с привычной структурой Windows: рабочий стол, панель задач, меню «Пуск», проводник и настройки.
  - После этого я бы начал добавлять специализированные инструменты для программистов.
  - В конце можно было бы объединить всё в единую систему и добавить собственные программы и утилиты.

Поясните, какие бы вы использовали инструменты или технологии.
--
  - **Linux** в качестве основы операционной системы.
  - **C и C++** для системных компонентов и низкоуровневых программ.
  - **Python** для различных утилит и автоматизации.
  - Компиляторы и интерпретаторы для разных языков программирования.
  - Инструменты искусственного интеллекта для помощи при написании и исправлении кода.
  - Утилиты, похожие на **Microsoft PowerToys**.
  - **Wine** или аналогичный совместимый слой для запуска Windows-программ.

Какой язык наиболее подошел бы для этого?
--
  - Для системной части я бы использовал **C и C++**.
  - Для вспомогательных программ, автоматизации и различных системных инструментов — **Python**.
  - Для отдельных компонентов можно было бы использовать **Rust**.
  - Для разработки графического интерфейса можно было бы использовать C++, Rust или другие подходящие технологии.

Для чего создавалась ваша ОС?
--
  - Основной целью было бы создание удобной рабочей среды для программистов и разработчиков.
  - В системе были бы встроены компиляторы и интерпретаторы для различных языков программирования.
  - Пользователь мог бы сразу писать, компилировать и запускать программы без необходимости самостоятельно устанавливать большое количество инструментов.
  - Также система предоставляла бы специализированные функции для работы с кодом, файлами и проектами.
  - Ещё одной особенностью была бы возможность запуска **EXE-файлов Windows**.
  - В систему можно было бы встроить инструменты для конвертации или перевода кода между языками программирования.
  - Также был бы встроенный ИИ-помощник, который мог бы объяснять ошибки, анализировать код и помогать с программированием.
  - Дополнительно были бы встроены различные системные утилиты, похожие на PowerToys, например расширенное управление окнами, быстрый поиск, массовое переименование файлов и другие инструменты.

Чем вы вдохновлялись при создании?
--
  - Интерфейсом **Windows**.
  - Возможностями и гибкостью **Linux**.
  - Набором инструментов **Microsoft PowerToys**.
  - Современными IDE и редакторами кода.
  - Идеей создания операционной системы, в которой большинство необходимых программисту инструментов уже встроено в систему.
